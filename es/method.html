Método antiestafa en 60 segundos

🕵️

La web falsa “casi perfecta”

Una página fraudulenta puede verse profesional. Prueba “Acerca de”, “Contacto”, “FAQ” o el logo: algunas webs falsas solo copian una página. Pero una web completa también puede ser falsa. El dominio exacto sigue siendo la comprobación principal.

1. Para
No respondas bajo presión. Un problema real puede verificarse sin seguir el enlace recibido.
2. Mira la dirección
Comprueba el dominio exacto: una sola letra puede llevar a otro sitio.
3. Prueba sin confiar
Acerca de / Contacto / FAQ pueden revelar una copia incompleta. Es una pista, no una prueba.
4. Cierra
Ante la duda, cierra la página aunque parezca auténtica.
5. Empieza de cero
Abre tú mismo la app oficial o escribe la dirección oficial.
6. Confirma
Si la alerta no aparece en tu cuenta oficial, trata el mensaje como sospechoso.
⭐

La regla de oro

Si un mensaje te lleva a un enlace, no continúes navegando desde ahí. Cierra la página, abre tú mismo la web o app oficial y comprueba tu cuenta allí.
